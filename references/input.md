# 当周数据填写口径

`classes` 是当周完整班级名册。每个项目在 `rows` 中为名册的每个班提供成绩依据。综合页要列的项目须有 `events`，来源确认本周无问题时填 `[]`。可用这个单班示例了解字段，实际填入本周全部班级。

```json
{
  "grade": 2026, "week": 14, "issued": "2026-11-28",
  "classes": ["机械261"],
  "sections": {
    "时政学习": {
      "rows": [{"class":"机械261","values":["2B201","林青",32,31,20,"良好",15,24,12.5,"良好",12.5,14]}],
      "events": [], "notes": ["机械261请假：{沈清远} 参加比赛"]
    },
    "晚自习": {
      "rows": [{"class":"机械261","days":[100,94,100,null,100],"score":98,
                "audit":{"registered":98,"source":"晚自习单表!G6（登记）、B6:F6（各日明细）",
                         "reason":"原公式漏计周四，部门已确认登记分作为正式周分"}}],
      "problem_groups": ["旷晚自习"],
      "events": [{"date":"2026-11-23","class":"机械261","issue":"旷晚自习","names":["林青","周明远"]}]
    },
    "早操": {
      "rows": [{"class":"机械261","days":[null,null,null,null,95]}],
      "events": [{"class":"机械261","issue":"迟到","names":["周明远"]}]
    },
    "宿舍卫生": {
      "header_date":"2026-11-27",
      "rows": [{"class":"机械261","room":"9#301","condition":"二号床未叠被","points":91},{"class":"机械261","room":"9#302","condition":"良","points":96,"mixed":true}],
      "events": [{"class":"机械261","room":"9#301","bed":"二号床","issue":"未叠被"}]
    },
    "教室卫生": {
      "header_date":"2026-11-27",
      "rows": [{"class":"机械261","room":"2B201","days":[100,100,100,100,100]},
               {"class":"机械261","room":"2B101","public":true,"days":[100,95,100,100,100],"remarks":"11.23 黑板未擦"}],
      "events": [{"date":"2026-11-23","class":"机械261","room":"2B101（公共教室）","issue":"黑板未擦"}]
    },
    "宿舍安全": {
      "rows": [{"class":"机械261","score":95,"check":"无","hazard":"9#301 二号床 {林青} 未断电"}],
      "events": [{"date":"2026-11-24","class":"机械261","room":"9#301","bed":"二号床","names":["林青"],"issue":"未断电"}]
    }
  }
}
```

## 成绩字段

| 项目 | 对应样表的栏目和计算 |
| --- | --- |
| 时政学习 | `values` 按 B 至 M 依次为教室、团支书、应到、实到、人数成绩、记录情况、记录本成绩、PPT 成绩、桌面卫生分、纪律情况、纪律分、政治学习总结分。总成绩加总 F、H、I、J、L、M 六个评分栏。 |
| 晚自习、早操 | `days` 固定五个位置。晚自习按周日到周四，早操按周一到周五。未检查的位置留 `null`，实得零分填 `0`。按实际检查日取平均。实际检查日缺报且有已确认采用分时，留空并在 `audit` 标明待核实。 |
| 宿舍卫生 | 每班每次检查的每间宿舍各一行。将同班在原表左右两栏的全部有效明细归到同一班，纳入末行和“良”等正常记录。共用宿舍以各班实际记录为准，确认混合宿舍填 `mixed: true`。同班 `score`、`audit` 各填一次，放在该班任一行。 |
| 教室卫生 | 每个普通班一行，`days` 按周日到周四。公共教室另设 `public: true` 行，归入实际负责班，保留该教室自身日分及备注。样表综合取本班普通教室周分；若当周有正式合并成绩，把确证的班级周分作为普通行的 `score`。 |
| 宿舍安全 | `score` 是已确认采用的班级量化分，`check`、`hazard` 分别是查寝和安全隐患的详情。按原单区分空白和“无”。 |

`score` 是确认后采用的分数。来源只有正式周分时，填写 `score`，未提供的明细留空（`null`）。时政使用十二个对应位置，日分使用五个位置，宿舍卫生可用只有班级和正式周分的一行。明细足以计算且与正式周分一致时，可省略 `score`，让分表用公式复算。明细缺报或是否计入待确认时，用 `audit.pending` 记录，并填写已确认可采用的 `score`。没有可采用的分数时需核实后再生成。

综合分项按样表的一位小数口径汇总，六项相加。生成时按总分降序排列，同分按班序展示且名次并列，并列后跳号。分项、总计和排名均为可重算的 Excel 公式。若在 Excel 中修改分数，用排名列对综合成绩区整行重新排序。宿舍卫生、教室卫生的 `header_date` 用于分表日期，按该表实际日期填写。正式落款始终取 `issued`。

## 登记分、复算分和采用分

- **原始明细**填入 `values`、`days` 或各行 `points`。逐项核对原始单元格，按班独立复算。宿舍卫生以核实后的有效房间为准，逐间对照原公式引用，确认没有漏掉末行、混合宿舍或误用相邻班级成绩。
- **分表登记分**填入成绩行的 `audit.registered`。登记栏确实空白时填 `null`。遇到差异、补分或待核实，`audit.source` 写明来源文件或表名及单元格，注明登记分位置和复算明细范围，若有补分还要列出补分出处。`audit.reason` 说明差异及采用原因。尚未确认的情况写明待核实的内容，明细计入范围不确定时加 `"pending":true`。
- **综合页采用分**取生成分表的对应成绩单元格。填写 `score` 时以该值为准，脚本仍计算可得的明细复算分。确认应改用复算分时，可省略 `score` 保留分表公式，并在 `audit.reason` 说明依据。只提供对照表时，先核实补分是否为正式周分，再填写 `score`。
- 脚本把差异说明写在分表采用分的单元格批注，包含班级、来源单元格、登记分、复算分、原因和采用值。只有部分明细可确认时，批注注明复算分为暂算值并标明待核实。普通班的公式引用与对照核验均以“班级名＋项目名”为键。

例如，原登记栏空白、已核实汇总表中的补分可采用时，在该班对应成绩行填写如下字段。

```json
{
  "score": 96,
  "audit": {
    "registered": null,
    "source": "分表!G8（空白），学院当周汇总!C12（补分）",
    "reason": "已核实汇总表补录的正式周分"
  }
}
```

## 排版顺序和通报范围

- 仅在用户明确指定排版样表时，在 JSON 顶层填写 `sheet_order` 和 `score_order`，分别逐项抄录样表的七个页签及综合成绩区六个项目的顺序。名称使用技能标准名称，例如“政治理论学习”对应“时政学习”。班级、总计和排名沿用综合页模板中的位置。只有用于对照的当周成表时，省略这两个字段，沿用默认顺序。
- `report_subjects` 是可选的顶层字段，按用户要求填写综合通报要列的项目和顺序，例如 `["晚自习","教室卫生"]`。省略时按默认顺序列六项。用户明确不需要综合通报时可填 `[]`。这项配置独立于排版样表和成绩列。六项分数始终填写。未选入综合通报的项目依然可提供 `events` 供分表备注使用，来源缺失则省略 `events`。

## 通报和姓名

- `names` 按一人一项填写。“全班纪律乱”一类集体问题直接填完整 `issue`，省略名单。多人共用同一问题、日期、班级、地点和床位时可合为一条记录。不同日期或不同问题分别保留。
- 共同归属多班的同一通报可用班级数组，如 `"class":["机械261","机械262"]`；成绩明细的 `class` 始终为单个班级。晚自习必须带检查日期，其余项目有日期就填。日期均为 YYYY-MM-DD。
- 在自由文字（含情况、纪律、备注、查寝、安全隐患）中，用 `{林青} {周明远}` 标记名单，姓名之间放一个空格。团支书栏和 `names` 数组直接填原名，无需花括号。脚本会排成“林　青 周明远”，行末放不下时整名移到下一行。
- 时政学习、晚自习和早操分表有独立备注区。只需在 `notes` 补充分表独有的请假原因等。其他三张表的原始说明放回各自的情况、备注或安全栏目，综合通报使用核对后的 `events`。
